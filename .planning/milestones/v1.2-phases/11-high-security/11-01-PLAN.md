    Sync `isPrivateHost(host: string): boolean` returns true for:

    Async `isPrivateHostWithDns(host: string): Promise<boolean>`:
    - If host is already an IP literal → returns isPrivateHost(host) (no DNS)
    - Otherwise: dns.promises.resolve4(host) AND dns.promises.resolve6(host) (both, swallow ENOTFOUND/ENODATA on either)
    - If ANY resolved IP returns isPrivateHost(ip) === true → return true (rebinding-safe)
    - If both resolutions fail entirely → return true (fail closed — refuse unresolvable hosts for security-critical writes)
    - Wall-clock timeout: 2s total via Promise.race against setTimeout. Timeout → return true (fail closed)

    Optional named export `PRIVATE_HOST_REASONS` (object) mapping check names to human-readable strings — used by callers for 400 error messages (e.g. `{ loopback: 'loopback address', linkLocal: 'link-local address', ula: 'IPv6 unique local address', metadata: 'cloud metadata host', dnsFailed: 'host could not be resolved' }`). Not load-bearing — error messages can be generic "private/internal host not allowed".

    IPv6 parsing: use Node's built-in `net.isIP(host)` (returns 4, 6, or 0) and `net.isIPv6`. Do NOT roll a custom IPv6 parser. For the fc00::/7 and fe80::/10 checks, normalize via expanding leading zeros: split on ':', pad each group to 4 hex chars, concat — then check first 8 hex chars.

    No external dependencies. Use only `node:dns/promises` and `node:net` (already available in Node 20+).

    Create `src/server/lib/network-guard.ts` implementing the behavior above. Structure:

    ```ts
    import { promises as dns } from 'node:dns'
    import net from 'node:net'

    const METADATA_HOSTS = new Set([
        'localhost',
        'metadata.google.internal',
        'metadata',
        'instance-data',
        'instance-data.ec2.internal',
    ])

    export const PRIVATE_HOST_REASONS = { /* ...as in behavior */ } as const

    function ipv4IsPrivate(ip: string): boolean { /* parts check incl. 100.64/10, 169.254/16, 224/4 */ }
    function ipv6IsPrivate(ip: string): boolean { /* normalize, check ::1, ::, fc/fd, fe80–febf, ::ffff:IPv4 → delegate */ }

    export function isPrivateHost(host: string): boolean {
        const h = host.toLowerCase().trim()
        if (METADATA_HOSTS.has(h)) return true
        const kind = net.isIP(h)
        if (kind === 4) return ipv4IsPrivate(h)
        if (kind === 6) return ipv6IsPrivate(h)
        return false  // hostname — caller must use isPrivateHostWithDns for SSRF-critical paths
    }

    export async function isPrivateHostWithDns(host: string): Promise<boolean> {
        const h = host.toLowerCase().trim()
        if (METADATA_HOSTS.has(h)) return true
        const kind = net.isIP(h)
        if (kind) return isPrivateHost(h)

        const timeoutPromise = new Promise<boolean>((resolve) => setTimeout(() => resolve(true), 2000))
        const dnsPromise = (async () => {
            const results = await Promise.allSettled([dns.resolve4(h), dns.resolve6(h)])
            const ips: string[] = []
            for (const r of results) if (r.status === 'fulfilled') ips.push(...r.value)
            if (ips.length === 0) return true  // fail closed — unresolvable
            return ips.some(isPrivateHost)
        })().catch(() => true)

        return Promise.race([dnsPromise, timeoutPromise])
    }
    ```
