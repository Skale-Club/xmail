# Plan 14-02: CI Lint + tsc Gates

## Goal
Add `npm run lint` and `npx tsc --noEmit` as required CI checks so v1.2 quality bar stays green.

## Scope
- In: GitHub Actions workflow file with lint + tsc + build steps.
- Out: error log sink (separate plan 14-03 CI-04).

## Tasks

### Task 1: Inspect existing CI
- Read `.github/workflows/deploy-hetzner.yml` and `.github/workflows/keepalive.yml`.
- Decide: add a new `ci.yml` workflow (recommended — keeps deploy separate) OR extend existing deploy workflow.

### Task 2: Create `.github/workflows/ci.yml`
- Trigger: `push`, `pull_request` to `main`.
- Steps:
  - `actions/checkout@v4`
  - `actions/setup-node@v4` with node 20.x (match local).
  - `npm ci`
  - `npm run lint` (must exit 0; --max-warnings 0).
  - `npx tsc --noEmit -p tsconfig.json`
  - `npx tsc --noEmit -p tsconfig.server.json`
  - `npm run build`
- Concurrency group to cancel in-progress on same ref.
- Required to merge: configure branch protection later (out of scope).

## Verification
- `cat .github/workflows/ci.yml` exists and contains lint + tsc + build steps.
- Manual: push a commit and confirm CI runs (deferred — operator verification).

## Files to touch
- `.github/workflows/ci.yml` (new)

## Dependencies
None (Phase 12 + 13 land lint+tsc already green).

## Risks
- Node version mismatch — pin to 20.x.
- `npm ci` requires `package-lock.json` — confirmed present.
